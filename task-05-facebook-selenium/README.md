# Task 5 — Post a Message to Facebook Using Selenium

## Objective
Demonstrate real-world browser automation using **Selenium WebDriver** and **Google Chrome** to interact with the Facebook web interface. The automation script navigates through the interface, opens the post composer dialog, stages a text post, and incorporates a **strict interactive confirmation safety gate** before any publish action can ever be taken.

---

## Security & Anti-Bot Principles

Automating actions on Facebook involves strict security, anti-bot mechanisms, and authentication challenges. In accordance with assignment instructions and ethical guidelines:

1. **Zero Credential Storage**:
   - Passwords, two-factor authentication (2FA) tokens, and session cookies are **never** hardcoded, stored in `.env`, or committed to the repository.
   - Authentication bypasses (e.g. attempting to automate CAPTCHA or bypass security verification checkpoints) are strictly prohibited.
2. **Persistent User Profile Workflow**:
   - The script supports a dedicated Chrome user profile directory (`task-05-facebook-selenium/chrome_profile/`).
   - This directory is explicitly ignored by [`.gitignore`](../.gitignore).
   - If the user is not logged in, the visible browser pauses and prompts the user to log in manually in the browser window. Once authenticated, cookies persist locally so repeated logins are unnecessary.
3. **Mandatory Safety Confirmation Gate**:
   - **No post is ever published automatically without explicit user confirmation.**
   - The script stages the post in the composer dialog, displays the exact text and target in the terminal, and pauses:
     ```text
     WARNING: You are about to publish a REAL post.
     Please review the staged draft in the visible Chrome window.
     Type 'yes' or 'CONFIRM' to publish this post (anything else to cancel):
     ```
   - If cancelled or if `--dry-run` is active, the script closes the modal, discards the draft, and terminates safely.
4. **Offline Demonstration & Testing**:
   - An authentic offline test fixture [`data/mock_facebook_feed.html`](./data/mock_facebook_feed.html) mirrors Facebook's DOM structure (`role="dialog"`, `role="textbox"`, `contenteditable="true"`), allowing full end-to-end automated testing without network access or risk to personal accounts.

---

## Technical Architecture & Selectors

Facebook's modern interface uses dynamic CSS-in-JS classes (generated by React and Relay) that mutate between builds. To ensure resilient automation, the script relies on semantic W3C accessibility attributes:
- **Composer Trigger**: `div[role="button"][aria-label*="What's on your mind"]`, `//span[contains(text(), "What's on your mind")]`
- **Post Modal Dialog**: `div[role="dialog"]`
- **Text Editor**: `div[role="dialog"] div[role="textbox"][contenteditable="true"]`
- **Publish Button**: `div[role="dialog"] div[role="button"][aria-label="Post"]`
- **Close Button**: `div[role="dialog"] div[aria-label="Close"]`

   ```bash
   google-chrome --version
   ```

   ```bash

   ```

## How to Run the Code

### 1. Offline Demonstration Mode (Local Mock Feed)
Run safely against the local offline HTML fixture with dry-run mode active:
```bash
python task-05-facebook-selenium/main.py --mode local --dry-run
```

To test the full publishing workflow against the local fixture without affecting Facebook:
```bash
python task-05-facebook-selenium/main.py --mode local --no-dry-run --auto-confirm
```

### 2. Live Facebook Mode (With Safety Gate)
To run against your own live Facebook account:
```bash
python task-05-facebook-selenium/main.py --mode facebook --text "Hello from Python automation!"
```
- A visible Google Chrome window will open.
- If you are not already logged in, the terminal will ask you to complete manual login in the browser.
- The script opens the post dialog and stages the message.
- You can review the post in Chrome.
- The terminal will ask for explicit confirmation before clicking the Post button.

### 3. Run Automated Unit Tests
Run the 8 offline unit tests in headless mode:
```bash
python task-05-facebook-selenium/tests/test_facebook_selenium.py -v
```
